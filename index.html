How to use JobRadar

Step 1 — Get your API key
Go to console.anthropic.com, create an account, then go to API Keys and create a new key. Paste it in the field at the top of this page. It stays in your browser only.

Step 2 — Set your filters
Use the left sidebar to choose which job titles, sources, language requirements, and skills to search for. Everything is pre-set for your profile already.

Step 3 — Search
Click the Search Jobs button. Claude will search job portals, read each listing, score it against your CV, and show the results here. Each run may take 1–2 minutes.

Step 4 — Review & Apply
Browse Strong Matches (score 5+) and Possible Matches (score 3–4). Click Apply Now to open the job link.
